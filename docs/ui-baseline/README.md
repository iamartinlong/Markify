## 怎么重新生成

不能用普通的截图工具——窗口尺寸、主题状态、鼠标位置都会影响结果。需要一个"设尺寸 → 等生效 → 点主题 → 再截"的脚本。

关键点（都是踩过的坑）：

1. **改完尺寸要等它真正生效**再截。`SetWindowPos` 是异步入队，立刻截图会截到旧尺寸。轮询 `GetWindowRect` 直到宽高匹配。
2. **点击坐标不能硬编码**。「深色」按钮的位置会随工具栏样式变化而移动。从当前截图里按"文字像素聚簇"反算按钮中心，或者量一次后记住。
3. **深色是否真的切过去了要用像素验证**，不要看截图觉得"应该是深色"。取工具栏亮度：浅色 ≈ 250，深色 ≈ 26。
4. **截图前决定鼠标放哪**。要静态外观就把鼠标移开；要悬停态就有意停上去。同一张图不能兼得（截图会包含光标位置）。

## 怎么比对

不要靠肉眼。逐区域取**众数颜色**再对照：

```js
// 取矩形区域内出现次数最多的颜色
function mode(img, x0, x1, y0, y1) { ... }
```

不要按单列或单行扫描——那一列可能恰好穿过若干同色文字，会被误判成"一条线"（见 pitfalls B13）。

比对判据（v0.6.0 的实测值，可作为下次的参照）：

| 项 | 期望 |
| --- | --- |
| 深色 菜单栏 / 工具栏 / 标签栏 | 三者同色（`#191A1B`） |
| 深色 编辑器 vs 预览 | **完全相同**（`#121314`，对比 1.000:1） |
| 分隔条 vs 两侧 | 1.2–1.4:1（可见但不刺眼） |
| 浅色 菜单栏 | `#FAFAFD`（不是纯白） |
| 工具栏选中按钮 | 强调色（`#2166D8` / `#4A85F3`） |

## 已知未覆盖

- 标题栏（非客户区）由系统绘制，深色下仍偏白。属第三期范畴。
- 侧栏的目录树 / 大纲在默认启动时是隐藏的（`IsOutlineVisible=false`），这四张图里看不到。要验证需先点「大纲」按钮。
